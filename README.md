# GitHubScraper [![Commit Status](https://github.com/LegendarySpork9/GitHubScraper/actions/workflows/Commit.yml/badge.svg?event=push)](https://github.com/LegendarySpork9/GitHubScraper/actions/workflows/Commit.yml) [![PR Status](https://github.com/LegendarySpork9/GitHubScraper/actions/workflows/Pull%20Request.yml/badge.svg)](https://github.com/LegendarySpork9/GitHubScraper/actions/workflows/Pull%20Request.yml)

Scrapes GitHub repository data — issues, commits, pull requests, workflow runs, and releases — and persists it to SQL Server. Generates daily aggregate statistics for tracking project activity over time.

## Tech Stack

| Technology | Version |
|------------|---------|
| .NET | 8.0 |
| Language | C# |
| Database | SQL Server |
